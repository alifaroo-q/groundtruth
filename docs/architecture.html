"Does CloudPulse's Pro plan support HIPAA compliance and SSO?"

BAAs are available on the Enterprise plan only

The FAQ never says "HIPAA", so search skips it.

3 · Engine answers wrong
"Every CloudPulse workspace runs on Enterprise-grade SOC2 and HIPAA security."

False. HIPAA needs the $499 Enterprise plan.

4 · GroundTruth outputs
A defect ticket, a git patch that adds ## Which plans include HIPAA? with the answer first, and JSON-LD for the page head.
